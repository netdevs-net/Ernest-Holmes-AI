## 🏗️ **Architecture Documentation**

### **Frontend (SvelteKit 5)**
- **Components**: Modular Svelte components with TypeScript
- **State Management**: Reactive Svelte stores
- **Styling**: Tailwind CSS with CSS variables
- **Routing**: File-based routing with SvelteKit

### **Backend (SvelteKit API)**
- **API Routes**: RESTful endpoints for all functionality
- **Database**: SQLite with better-sqlite3
- **AI Integration**: Claude 3 Haiku with Anthropic SDK
- **Authentication**: Anonymous user identification

### **Content & Data**
- **Training Data**: 463K+ words from Ernest Holmes' works
- **Quotes Database**: 17K+ authentic quotes
- **Question History**: Persistent storage with categorization
- **User Analytics**: Anonymous usage tracking
