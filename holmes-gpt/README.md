# HolmesGPT: Ernest Holmes AI

A spiritually attuned conversational AI designed to emulate the voice, style, and metaphysical insight of **Ernest Holmes**, author of *The Science of Mind*.

## 🌟 Features

- **Authentic Holmes Voice**: Responses in Ernest Holmes' characteristic style and language
- **Spiritual Guidance**: Metaphysical insights grounded in Religious Science principles
- **Beautiful UI**: Elegant chat interface with Holmes-inspired design
- **Real-time Chat**: Smooth, responsive conversation experience
- **Mobile Responsive**: Works beautifully on all devices

## 🚀 Quick Start

### Prerequisites

- Node.js 18+ 
- Anthropic API key for Claude Haiku

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/holmes-gpt.git
   cd holmes-gpt
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Set up environment variables**
   ```bash
   cp env.example .env
   # Edit .env and add your Anthropic API key
   ```

4. **Start the development server**
   ```bash
   npm run dev
   ```

5. **Open your browser**
   Navigate to `http://localhost:5173`

## 🧰 Tech Stack

- **Frontend**: Svelte 5 + SvelteKit
- **Styling**: Tailwind CSS
- **AI**: Claude 3 Haiku (Anthropic)
- **Language**: TypeScript
- **Deployment**: Vercel-ready
